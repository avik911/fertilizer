# Field & Flourish

A responsive, accessible fertilizer shop homepage built with React, TypeScript, and Vite.

## Run locally

```bash
npm install
npm run dev
```

Open **http://localhost:5173**.

## Quality checks

```bash
npm run lint
npm run test
npm run build
```

## Included

- Responsive storefront navigation and hero search
- Crop-based categories and filterable products
- Loading, empty, and recoverable error states
- Grower guidance and newsletter confirmation
- Keyboard focus, semantic landmarks, reduced-motion support, and mobile layouts
