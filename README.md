# Field & Flourish

A responsive fertilizer-shop homepage built with React, TypeScript, and Vite. It includes product search, crop categories, cart feedback, product loading/empty/error states, growing guidance, a newsletter form, and an accessible mobile navigation.

## Run locally

```bash
npm install
npm run dev
```

Open **http://localhost:5173**.

## Quality checks

```bash
npm run build
npm run lint
npm test
```

## Accessibility and responsive behavior

The page uses semantic landmarks, labeled form controls, keyboard-operable navigation, a skip link, visible focus states, reduced-motion support, live feedback, and layouts designed down to 320px.
