# Field & Flourish

A responsive fertilizer-shop homepage built with React, TypeScript, and Vite. The storefront includes product search, cart feedback, responsive navigation, product loading/empty/error states, grower guidance, and an accessible newsletter form.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Quality checks

```bash
npm run lint
npm test
npm run build
```

To preview the recoverable product error state, visit `http://localhost:5173/?productState=error#shop`.
